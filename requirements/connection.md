# 连接、身份与多会话

Owner：mod + cli。状态：部署目标 MUST；本地适配器与 wire 方案 TBD。

| ID | 行为与限制 | 验收 |
| --- | --- | --- |
| CON-01 | 专用服和已发布 LAN 的整合服由 Mod 在实际游戏监听端口接入控制连接；普通玩家连接照常。源服无需 Go daemon、SSH、外部分流代理或第二公网控制端口。 | 实际专用服和 LAN 上玩家与控制并存；正常协议未被误识别，坏帧只影响控制连接。 |
| CON-02 | 使用成熟加密方案验证服务端身份并认证调用者；支持凭证配置、撤销/轮换与服务端权限，协议识别仅负责路由。 | 正确身份通过；错误 pin/身份、错误凭证、撤销、权限不足、协议不匹配被明确拒绝。 |
| CON-03 | 控制会话身份独立于玩家，连接保持玩家实体与驻留条件。 | 零玩家服务器可连接；连接/断线前后玩家列表、加载和驻留状态一致。 |
| CON-04 | 多 daemon 各自直连 Mod，分别维护响应路由、权限和事件消费。 | 两个独立进程并发查询和受控写；请求/响应与权限绑定各自会话。 |
| CON-05 | 稳定实例身份与每次运行身份分开；目标选择显式，游戏重启、世界切换、daemon 重启可诊断。 | 同世界重启 run 变化；切换目标/世界后缓存和请求账本绑定新身份，连接结果报告实际目标。 |
| CON-06 | CLI 短调用与 daemon 长连接独立于 harness 生命周期；重连有界退避和状态，非幂等写经请求状态查询决定后续动作。 | harness/CLI 退出后 daemon 保持游戏连接；游戏重启恢复后有新身份；unknown 写仍可追踪。 |
| CON-07 | 网络线程与游戏线程分离；握手、帧大小、连接数、待处理请求、队列和超时有界。每会话队列与游戏和其他会话解耦。 | 畸形帧、超大消息、停读连接、满队列与并发压力；记录 tick 和正常会话响应影响。 |
| CON-08 | daemon 本地调用入口具备明确访问边界、实例锁/并发启动保护、版本检查、健康检查和优雅停止；本地 IPC 限定本机访问。 | 两次启动、陈旧锁/状态、错误版本、非预期本地调用者、终止信号及清理失败可诊断。 |
