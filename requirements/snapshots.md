## 强度与限制

不要求 JVM 内存检查点或任意 Mod 完整恢复。移动活塞、block events、计划流体刻、RNG、loaded/ticking 条件和跨 tick 状态必须逐项审计，不能把未验证状态泛称“全丢”或“完全恢复”。

候选 tick 边界需要当前游戏源码审查与实测；旧 PR 的候选 hook 不自动成为新产品实现。不能把“全世界”描述为“当前已加载维度的部分数据”。

Agent 选择加载、重建、静止起点或其他方法。核心不规定关机、生成电路、freeze/save/copy/summon 模板，也不管理实验实例、restore、merge 或 world promotion。
